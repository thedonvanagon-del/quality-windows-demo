# Brand and claims check

This is a working checklist, not legal advice. Confirm anything borderline with whoever handles compliance for the business.

## What the linter catches

`studio.py lint` flags: cure, treat, heal, diagnose, prevent, anxiety, depression, pain, insomnia, cancer, FDA-approved, guarantee, miracle, clinically proven. A flag means rewrite, not argue.

## Beyond the linter

- **No medical claims.** Don't say CBD or CBG helps, relieves, calms, or fixes anything. Describe the product and the experience of drinking it: what's in it, how much, how it tastes.
- **Amounts are facts.** Quote milligrams only from the product label or lab report. Never round up.
- **Sourcing is a claim.** Origin, altitude, farm, process, and "rare" all need to be true and provable. If the user didn't give it, leave it out.
- **Reviews are real.** Quote verbatim from real customers. Never write a testimonial. Mark the attribution honestly ("Verified customer" only if verified).
- **Age and legal.** Hemp-derived product rules vary by state and platform. Several ad platforms restrict CBD ads. Flag that for the user when the target is paid social.
- **Music and footage.** Licensed or user-supplied only.

## Voice check

Read the script out loud. If a line sounds like an ad, cut it down to what's true and specific. Plain verbs. Short sentences. Nothing puffed up.
