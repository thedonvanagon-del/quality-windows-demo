# Morning Meditations

One short guided meditation per day, built for Instagram Reels. File name is the date: `YYYY-MM-DD.md`.

## Length

Target 60 to 90 seconds. Never over 2 minutes. Reels run longer than that (3 minutes for most accounts), but a short one gets watched to the end.

## Format

Each file has the same pieces:

| Piece | Notes |
| --- | --- |
| Script | Timed in 5 to 25 second blocks. Silences marked `[pause N seconds]`. Keep them in. |
| On-screen text | 4 to 5 short lines, tied to timestamps. |
| Caption | A few short lines, one question at the end, a handful of hashtags. |
| Pairing note | One line on a coffee and brew method. |

Every script runs the same arc:

1. **Hook** (0:00 – 0:08). Say what this is and how long it takes.
2. **Breath** (to 0:30). Two slow breaths.
3. **Body or season** (to 0:55). Drop the shoulders. Name the weather or the light.
4. **The cup** (to 1:15). One sensory detail: smell, steam, warmth in the hands.
5. **One word and close** (to 1:30). Pick a word. Open the eyes. First sip.

## Voice

Plain verbs. Short sentences. Warm, not soft. Sensory detail about coffee: smell, sound, taste, warmth in the hands. Talk to the listener as an equal.

## Rules

- Change the theme daily. Lean on the season and the date.
- Rotate the cup image so it doesn't repeat back to back (the bloom, the aroma, the steam, the first sip, the grower's hands).
- No medical claims. No miracle language. If CBD or CBG comes up, keep it factual and about what people actually experience.
