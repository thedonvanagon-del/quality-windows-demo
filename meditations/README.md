# Morning Meditations

One 30-minute guided meditation per day. File name is the date: `YYYY-MM-DD.md`.

## Format

Each script has the same six parts and the same clock:

| Part | Time |
| --- | --- |
| 1. Arrive | 0:00 – 3:00 |
| 2. Breath | 3:00 – 8:00 |
| 3. Body | 8:00 – 14:00 |
| 4. The Cup | 14:00 – 22:00 |
| 5. Intention | 22:00 – 27:00 |
| 6. Return | 27:00 – 30:00 |

Silences are marked `[pause N seconds]`. Keep them in.

## Voice

Plain verbs. Short sentences. Warm, not soft. Sensory detail about coffee: smell, sound, taste, warmth in the hands. Talk to the listener as an equal.

## Rules

- Change the theme daily. Lean on the season and the date.
- Rotate the practice in "The Cup" so it doesn't repeat back to back (the bloom, the bean's journey, the aroma, the first sip, gratitude to growers).
- No medical claims. No miracle language. If CBD or CBG comes up, keep it factual and about what people actually experience.
